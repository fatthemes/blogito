# Changes to Blogito
## [Unreleased]
- Fixed a crash when a post title or commenter name contains a "%" sign
- Fixed the featured slider showing a blank area with one sticky post
- Fixed the empty "Read more" button in the list layout
- Fixed category colours and images not showing on category pages
- Fixed the header listing every page when no menu is assigned
- Fixed hidden social links appearing when no Social menu is assigned
- Clarified where each widget area appears
- Fixed the sidebar being unreachable on mobile with infinite scroll
- Renamed the Classic layout option to show it includes a sidebar
- Fixed dropdown menus running off the right edge of the screen
- Improved keyboard navigation for menus, the side panel and search
- Side panel and search now close with the Escape key
- Improved colour contrast for buttons and post navigation labels
- Added reading typography, reading time, author box, back-to-top button, reading progress bar and card hover options (Customizer → Reading & Extras)
- Added block editor styles and wide/full alignment support
- Added an option to turn off the header hiding on scroll
- New features are off by default on existing sites
- Added WooCommerce support: shop, product, cart, checkout and My Account pages styled to match the theme
- Added a header cart link with an item count, shown when WooCommerce is active
- Added a Shop Sidebar widget area and shop options (Customizer → WooCommerce (Blogito))
- Added WooCommerce to the recommended plugins
- Sites already using WooCommerce will see their shop restyled
